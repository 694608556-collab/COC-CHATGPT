# 安卓移植第一阶段结果

开始于 2026-10-12，首阶段验证完成于 2026-10-13。此阶段是可在真机运行的开发版，不是正式移植全部完成。

## 已实施

工程位于 `E:\COClogbook\1\mobile`，独立依赖及安卓构建，不改桌面业务源码。正式包名配置 `coc.logbook`；实际调试安装包 `coc.logbook.debug`，显示“COC 跑团记录簿（开发版）”。沿用原图标、配色，三个底部入口分别为跑团记录、角色卡、数据与设置。

- 首次保存目录确认及可读写校验；未确认、取消或位置不可用时不进入业务页面。
- 备份结构、实体标识与关联、正文来源、ZIP 路径及附件摘要校验。
- 导入预览、显示覆盖范围、设置单独勾选；用户确认后先保存并回读安全副本，再进行事务覆盖。
- 内部 SQLite 分块快照存储，带版本序号防止旧预览覆盖新状态。没有移植完整桌面 SQL schema，不声称已完成所有数据库迁移。
- 模组/场次浏览、已有正文离线阅读、正文搜索/过滤与分页；角色卡只读浏览。
- 单场次 TXT 与完整安卓文字备份保存，创建新文件不覆盖既有用户文档。

未实施的操作在界面明确说明，不用可点击的假按钮或演示数据冒充真实能力。未加入资料或闲记页面/存储，没有恢复角色卡 Excel/PDF 导出。

## 备份互通限制

安卓备份使用 `format=coc.logbook.android`、formatVersion=1 的独立外层信封。当前桌面恢复会因外层无 schemaVersion 而拒绝，避免现有整库恢复清空资料/闲记或删除离线正文。安卓可以读入该格式；桌面安全恢复安卓备份仍需专门开发和验收，不能直接使用当前电脑版旧恢复流程。

当前导入只恢复保留的业务数据，ZIP 附件校验但不搬运，导入预览明确提示这一阶段限制。旧 ZIP 原本没有正文，独立测试备份带有授权补充正文，并非声称旧 ZIP 自身已有这些内容。
