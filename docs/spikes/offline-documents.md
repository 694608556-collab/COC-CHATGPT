# 离线文档与表格验证

日期：2026-09-10

## 结论

- TXT 使用 UTF-8 直接生成。
- DOCX 使用纯 JavaScript 的 Office Open XML 生成器，不需要 Word。
- PDF 使用 Electron 内置打印引擎从受控 HTML 生成，不执行日志中的脚本，也不需要 Word 或 LibreOffice。
- 该方案比随包附带 LibreOffice 更小、更少子进程锁问题，仍满足无网和无 Office 环境生成 DOCX、TXT、PDF 的产品要求。

## 验证结果

- 连续隐藏生成 20 份 A4 中文 PDF：20/20 成功，单份 26,159 字节，文件头和非零长度校验通过。
- DOCX 文件头、压缩结构和非零长度自动测试通过。
- 中文、空格文件名通过。
- XLSX、旧 XLS、UTF-8 CSV 均转换为统一二维网格；多工作表与合并区域保留。
- CSV 中文乱码测试曾失败，读取层改为显式 UTF-8 解码后通过。

## 限制

- 第一版不提供任意 Office 文档的通用格式转换，只为应用内规范化日志和角色卡生成目标文件。
- 海豹站点直接提供的四种文件按原格式下载；TXT、PDF 和合成文件由应用本地生成。
