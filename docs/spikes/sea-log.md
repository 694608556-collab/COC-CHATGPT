# 海豹日志协议验证

日期：2026-09-10

## 已确认

- 只接受 `http://` 或 `https://` 开头、主机严格为 `log.weizaima.com`、带非空 `key` 参数的完整网址。
- 页面是前端应用，当前客户端资源调用 `https://dice-api.weizaima.com/dice/api/load_data`，使用 `key` 和可选的片段密码。
- URL 片段只在本地解析，不记录到普通日志；API、页面和资源重定向均需要再次验证协议和主机。
- 网络失败、超时和 5xx 归为“检测失败”；明确 404/410 或不可识别正文归为“失效”。网络失败不能覆盖上次成功内容。
- 原始响应规范化为消息顺序、时间、显示名、平台账号、正文、类型、骰子/场外标记和图片引用，并保留响应哈希与解析版本。
- 日期在过滤前从第一条有时间的消息中解析。八项显示过滤均可基于标准化缓存离线重放。

## 自动验证

- 三种有效响应形态由固定 JSON 固件覆盖：顶层数组、`data.logs`、`messages`。
- 无正文、404、5xx、断网和超时由固定测试覆盖。
- 八项过滤均有独立断言，测试不依赖在线网站。

## 在线验证边界

公开页面本身不包含日志正文，示例链接的片段可能是访问口令。未经用户明确授权，开发测试不会把该口令提交到站点。适配器已隔离在线协议；取得三份用户授权的脱敏有效链接后，只需补做协议兼容验收，不影响其余本地功能。

## 适配器边界

`parseSeaLogUrl` 负责本地验证；`buildSeaApiUrl` 负责构造站点请求；`normalizeSeaResponse` 只把不受信任响应转为纯数据，不执行站点脚本或 HTML；`applyLogFilters` 只处理规范化数据。
