# UI 试验 2：触摸入口、场次工具栏和长弹窗

接续试验一 `bf0b4fd162e81adf3ead4cebcfbb7048f9e1b78f`，仍在 `codex/ui-optimization-experiment`。页面标记为“0.2.14 · 试验 2”，包版本及 versionCode 仍为 0.2.14 / 17。公司没有安卓手机，本轮只有浏览器和网页构建检查。

## 完成内容

- 返回、搜索清空、排序手柄、左滑删除使用至少 48×48 CSS px 的按钮范围；搜索输入和场次操作按钮至少 48px 高，阅读设置整行勾选区域至少 48px 高。图标尺寸、原字体、色彩与圆角保留。手柄占用独立布局空间，不覆盖正文按钮；不使用重叠透明点击层。这些是浏览器尺寸，不代表 Android 实际 dp 或手指验收。
- 普通场次工具栏突出“新增手动场次”，在线新增及全选保留。批量删除只在多选模式显示；多选期间集中显示全选、退出、获取正文、批量／合成导出及删除，新增入口在退出多选后恢复。删除放在批量操作末端，与常用操作拉开距离；已选数量仍放在整排末尾。删除确认、实际范围及即时排序契约不变。
- 表格预览、备份导入、导出及确认弹窗固定标题和底部操作区，中间内容单独滚动。全部场次名称与警告保留，长列表不再需要滚到底部才能确认／取消。操作按钮至少 48px 高，沿用面板底色和细灰分隔。
- 表格确认显示真实忙状态；失败在弹窗中显示原因。备份导入进度保持在固定标题下方，不能因长内容滚动而找不到进度。
- 延续试验一的 8px 卡片外间距、连续设置串行合并、CAS 与失败回退、十分钟有修改才备份；不改数据库／备份版本，不生成操作前副本。

## 验证

15 项受影响浏览器专项及完整 64 项浏览器回归通过，覆盖手柄不遮挡正文、48px 入口、多选退出后恢复新增、120 场预览、280px 窄屏／360px 短视口及浅深色。长预览滚动到顶部、中间和末尾时操作区仍在视口内，取消后原 4 场公开样本保留。类型、ESLint、格式、网页生产构建与 Capacitor 同步通过。

测试使用独立公开样本和独立浏览器上下文，未操作用户的实际正文。没有本轮原生 Gradle 编译、手机安装、S9／Android 9／WebView 78 或保留数据回退通过结论。
