# 姓名候选界面修正：1.0.8 / build47（验证中）

iOS build46 首轮公开失败的原始合成触摸与录屏已定位：期望点击网页Beta候选，实际触摸(108,534.57)落入原生键盘预测词栏第一项，录屏显示该项高亮后原精确断言得到`Public Beta `。后续原生几何取证还捕获候选被保存操作栏覆盖。不能将此前同源码复跑通过当成环境归因。

Android包含相同的两个网页组件，原生尾空格尚未在Android实体机复现。移植前，两项受控浏览器回归均失败：已聚焦输入只收到pointerdown时无法重开候选；按公开iOS原生数值模拟键盘平移时，姓名框211px被错误移到319px。这里只证明共享网页边界，不冒充Android原生键盘复现。
