# UI 与连续设置操作试验（2026-10-15）

本轮仅作试验，尚未由用户接受。试验分支为 `codex/ui-optimization-experiment`，页面标明“0.2.14 · 试验”。原开发分支 `codex/android-browser-edit` 保留在 `14efc294b5639c9444651cbd97980a29fd8dfa1a`，包含此前完整模组搜索、独立姓名候选、窄记录图标和导入预览超过 50 场的修复。本试验不推进原分支、不合并、不正式发布。

## 试验范围

- 三模块的普通卡片外间距统一为 8px：统计卡原为 20px，一般面板原为 12px，记录／正文卡原为 10px。已有 8px 间距保留；保留原字体、配色、圆角、卡片内边距和完整内容。
- 阅读过滤、主题、自动备份选项可连续选择。第一笔立即提交，写入期间只合并后续最新设置，前一笔成功后再提交；没有并发写入，也不额外延迟第一笔落盘。其他写操作仍由原锁串行保护。
- 每笔使用最近一次成功返回的版本。失败停止队列，恢复最后成功的设置，保留最新选择以供明确重试；陈旧版本仍拒绝覆盖。
- 快速保存不闪成功提示；等待超过 350ms 才显示模块内“保存中…”，全部成功后短暂显示“已保存”。状态预留位置，正常提示不撑开组件。失败明确显示原因和“重试保存设置”。
- 不改数据库版本、备份结构、正文、排序即时保存、默认十分钟有修改才备份或事务失败保护，不恢复操作前副本。

## 验证边界

54 项单元检查通过，包含在途合并、顺序版本、失败停留在最后成功版本及显式重试。完整 62 项浏览器回归通过，涵盖模拟慢写、快速保存／陈旧版本回退、280–840px、浅深色、排序、导入／导出及备份期间修改。类型、ESLint、格式、网页构建及 Capacitor 同步通过。旧测试对每次设置都显示“已保存”的断言已改为等待写入完成；通过结果来自更新断言后的完整重跑。

测试使用独立浏览器上下文和公开样本，没有覆盖用户当前预览中的跑团数据。公司没有安卓手机；本次设置写入耗时、旧 WebView、键盘和手指体验继续待实机检测。
