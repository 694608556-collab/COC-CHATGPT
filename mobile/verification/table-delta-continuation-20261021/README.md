相同公开夹具：50 模组、1000 条在线记录、每条 52000 字符正文，追加 6000 条无正文元数据，最终 7000 条。原生差量路径单次为 5123.902ms，其中记录处理/写入 4710.205ms；同次完整套件旧接口为 4861.428ms。结果没有表明仅缩小差量载荷即可提速大批追加。

优化在完整差量规则、完整合并图校验之后，复用一条 SQLite 插入语句，直接插入已证明是新增且无正文的记录，省去逐条重复查询、空正文删除和大小重算。明确含手动正文的新增仍使用原有有界正文写入。所有写入仍在同一授权/CAS事务内，保留最终全库容量检查与整批回滚。
