# 无安卓设备时继续开发

浏览器入口运行实际 MobileApp 页面，通过显式注入的 LogbookPort 接入 IndexedDB 测试存储。
正式入口 src/main.tsx 仍使用 Capacitor；不导入 src/dev 或公开测试样本。

## 启动

需要 Node.js 22+、pnpm。完整仓库先按根 README 安装依赖（共享 document-renderer.ts 仍依赖根目录 docx），再在 mobile 中运行：

```text
pnpm install --frozen-lockfile
pnpm dev
```

打开 http://127.0.0.1:4173 。服务器只监听本机。代码修改自动重编译，刷新网页查看。
首次点击「选择并确认保存位置」后确认启用测试存储；这不代表手机目录授权成功。
可以直接新增模组、手动场次和角色卡，也可以点击「载入公开测试数据」直接预览并确认导入，无需先下载。下载按钮提供相同完整样本，供文件导入测试。

公开样本包含 2 个模组、4 个场次：240 条在线格式离线正文、两份手动笔记、一个缺正文场次。
导入后打开「第一场：灯塔线索（240条）」，搜索「灯塔」有 3 条结果，分别位于第 1、2、3 页。
点击结果或「上一处/下一处」会定位到原正文，保留上下文；关键词在结果摘要和正文中高亮。
「a+b」用于字面符号匹配，「骰子专用词」用于隐藏骰指令后的搜索，「铜钥匙」可测试手动笔记。
搜索以当前过滤后的正文为范围，空白查询不产生结果；命中数按消息/行统计，每条可能高亮多处。
数据与设置提供「浅色模式/深色模式」，保存到当前存储后在下次打开时保留。主题写入失败不切换显示。

测试数据按浏览器、来源地址隔离，刷新后保留；清除站点数据会删除它们。
安全副本与导出保存在 IndexedDB，点击「刷新测试文件列表」后可下载到电脑。
浏览器只验证测试存储的写入/回读，不验证电脑下载落盘或安卓 SAF。

## 本轮编辑范围

- 模组：新增、名称、进度、KP；保留已有 PC/PL 关联。
- 场次：新增手动场次、编辑名称/模组/序号/日期及手动正文。在线场次编辑保留原正文、来源、缓存来源和获取时间。
- 角色：新增六版/七版；编辑基本信息、八项属性、当前 HP/MP/SAN、七版幸运、已有技能点分配、物品、已有背景、经历。隐藏技能和武器等未开放字段保留。
- 取消编辑不提交；离开未保存页面有提示；保存期间禁止重复操作。
- 编辑提交携带打开编辑页时的 revision。旧版本拒绝提交；安全副本失败不改数据库。
- 每次编辑保存生成 before-edit 安全副本，暂不自动清理；这不等于已完成定时自动备份。

尚未实现删除、完整关联管理、职业公式编辑、自定义技能增删、版次转换、武器编辑等。新增角色可先填写基础内容，不能当作桌面编辑器的完整替代。
原生 commitEdit 复用 commitRestore 的副本写入、回读与事务机制；本次只完成源码接入，待 SDK 构建和真机确认。
