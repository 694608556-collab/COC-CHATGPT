## 启动

需要完整仓库（含桌面字体资产）、Node.js 22+、pnpm。在 mobile 运行即可，无需安装桌面 Electron 或 Android SDK：

    pnpm install --frozen-lockfile
    pnpm dev

打开 http://127.0.0.1:4173 。目录授权在浏览器中是测试边界，确认后可新增数据或载入公开样本。
服务器只监听本机；海豹请求代理只接受现有 HTTPS API 并逐次校验跳转，不接受任意目标。
依赖变更或开发脚本变更需重启服务器；页面源码变更自动重编译，刷新查看。

## 手势与紧凑布局

模组不再使用下拉过滤，点击展开其场次，双击名称编辑；取消管理模组栏。左滑模组/场次/角色列表露出灰色圆角 ×，右滑或点击卡片可收回，点击删除后仍确认并保存安全副本。模组和场次从右侧 30 px 宽、至少 44 px 高的手柄直接上下拖动，松开一次提交顺序；仅能在同一模组内调整场次。触屏和鼠标均可操作，屏幕边缘自动滚动，松开/取消/失焦会清理拖动。

场次卡片长按后松开进入多选并勾选当前场次；正文继续移动则取消选择，不切换排序。左侧复选框在多选模式显示，各模组保留全选、退出多选、正文获取和批量/合成导出。

已选场数在全部模组按钮后单独一行。场次链接状态显示未检测、有效、失效、检测失败，手动场次显示手动内容；跑团时间在状态行末尾，使用已有 playDate，不推测时分。正文搜索输入即匹配，键盘回车定位第一处，框尾灰色 × 清空；移除搜索下方按钮和场次内三个隐藏开关，统一读取设置页规则。阅读操作按钮从左紧凑排列，宽度不足才换行。导出格式使用应用自身的菜单，保留六种格式和键盘操作。

纯图标返回调用同一导航保护。左右 10 px 边缘向内滑返回，最底部 12 px 上滑请求回桌面；不接管全屏普通滑动、不清除草稿，写入时拒绝应用内后台化。浏览器以提示模拟回桌面，不关闭浏览器。保存反馈固定显示，不推挤列表；确认导入的进度在弹窗内部先绘制。

角色简介显示版次、职业、年龄。属性和技能详情网格依据可用宽度排列，技能编辑为名称、最终数值、小灰色 ×，添加入口在前。不显示职业点总额覆盖、职业/兴趣点统计或分配/隐藏控件。修改技能数值时基础值取最终值、分项归零，未修改技能保留原值。物品改为逐项添加/输入/删除，武器按钮收紧。

技能详情采用面板底色和灰色细框；物品编辑及展示按宽度自动多列（常见手机宽度两或三列，极窄一列）。装备及背景复用中文字段标签，原始字段名、自定义背景、用户内容不改。取消全页粗紫色焦点外框，触摸选择使用底色和勾选；键盘焦点采用细灰色提示，不移除原字体。

KP 为逐项名单；PC 输入框内含角色候选，点击可绑定，手动输入则解除绑定；PC、PL、小灰色 × 同行。角色表格导入入口已移除。

全页按钮、操作栏、字段、设置选项和弹窗适配 280、320、360、393、412、430、600、840 CSS px。兼顾浏览器缩放、横屏和分屏，不依据手机型号判断；保留 chrome69 构建目标，flex 间距使用旧 WebView 支持的 margin。

浏览器顶部默认显示鼠标手势辅助，可关闭。场次的「模拟长按」进入多选，「模拟左滑」露出删除，「模拟拖动」后点击同一列表的目标项完成排序。辅助入口仅存在于开发预览，正式安卓构建不包含这些按钮。鼠标按住超过长按阈值后，横向左拖仍可触发删除；长按和拖动采用指针捕获，保留触摸滚动处理。

## 字体和已删除设置

使用桌面仓库的 SF Pro Display、SF Pro Text、PingFang SC 共八个字体文件。文件与基线 Git blob 哈希核对一致，用户已确认安卓嵌入授权。
构建打包完整字体，不按私人样本裁剪，不请求远程字体或读取本机同名字体。启动/PDF 导出等待加载，字体失败会明确报错。
首行缩进和深色导出样式已移除；导入旧标记时固定为 false，界面明暗主题仍可切换。
设置统计顺序为模组、场次、已保存正文、角色卡；窄屏两列，较宽屏四列。

PDF 当前为固定字体的页面图像，中文可见，但文字不可复制搜索；150 页上限，较大内容需分批。
带图 DOC 保留远程图片引用，未下载图片，不承诺断网显示。

## 备份与归档

自动备份支持修改后空闲、每日和每周；应用运行期间执行，系统暂停/关闭期间不保证定时任务，下次打开检查到期时间。
只轮换本应用登记且校验未被用户改动的自动文件，保留最近十份；手动、安全和用户自建同名文件保留。
归档 ZIP 包含登记的导出与迁移文件，不递归打包备份。JSON 仅含业务快照。旧 URI 不来自备份，目录授权始终单独确认。
恢复时只导入记录/模组归档，不导入电脑资料/闲记。先安全副本、再新建附件、最后事务提交，失败不覆盖旧文件。
浏览器文件存在 IndexedDB，需要下载才成为电脑文件。归档的打开/分享不接受任意外部 URI。
