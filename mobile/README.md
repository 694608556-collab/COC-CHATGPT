## 触屏与不同宽度适配

所有模组同页展示，点击展开、双击名称编辑。模组/场次/角色列表左滑露出删除，右滑收回；模组和场次从右侧手柄直接上下拖动排序，移除上移/下移按钮。卡片长按松开仅多选，继续移动取消选择；浏览器可用鼠标操作手柄，边缘自动滚动。删除仍确认并保存安全副本。纯图标返回、左右边缘向内滑返回和底部上滑请求回桌面沿用导航保护，不改变手机设置或清除草稿。

角色简介包含版次、职业、年龄；属性和详情技能网格按容器宽度排列。编辑技能仅显示名称和最终数值，改数值时将最终值存入基础值并归零分配分项，未编辑项目保留原数据。移除职业点总额覆盖及点数统计，物品逐项输入/增加/删除。KP 逐项编辑，PC/PL 同行，PC 输入框内的自定义候选列表可绑定角色，支持手动姓名。表单逐项删除使用小灰色 ×。

全页按钮、操作栏、输入框、设置选项和弹窗均适应可用宽度；验证 280–840 CSS px，属性/技能不固定列数。保留桌面内置字体；flex 间距使用 margin 以适配 WebView 78。

这是正式移植代码的首阶段工程，不再是独立技术探针，也不是已完成的正式发布版。桌面业务代码与依赖清单保持不动，安卓使用自己的 package.json、锁文件和原生工程。

## 身份与数据隔离

正式 applicationId 是用户指定的 `coc.logbook`。debug 构建增加 `.debug` 后缀，实际安装为 `coc.logbook.debug`，名称带“（开发版）”，不会覆盖独立技术验证版 `coc.logbook.spike` 或正式产品。当前源码配置 0.2.10-dev、versionCode 13，最低 Android 9 / API 28；只升级独立 `coc.logbook.performance.debug` 手势测试版，原开发版未安装本轮 APK。

APK 不携带用户备份、真实正文或按样本生成的字体。沿用桌面八个完整字体资产、原电脑图标和配色；本轮用户已确认具有这些字体的安卓嵌入授权。应用启动和 PDF 生成等待内置字体加载，文件加载失败会明确提示。

用户可见导出/备份通过 SAF 文档树授权操作，内部数据库位于应用私有目录。SQLite schema v2 保留 v1 的正文分块，增加元数据覆盖及版本序号，小改名/设置/排序不重写全部正文；重开和备份仍得到完整 schemaVersion 2 快照。分块避免 Android 9 CursorWindow 大行限制及 UTF-16 代理对截断。升级保留旧数据；不能清库替代迁移，也不能用只认识 v1 的旧 APK 回退。

旧电脑备份输入支持 schemaVersion 1 / 2 的当前已知业务结构。ZIP 校验 backup.json、路径、重复条目、清单文件大小与 SHA256；输入上限 64 MB、解压累计上限 128 MB、最多 2000 个条目。恢复跑团记录/模组附件，不导入资料和闲记附件；安全副本完成后创建新文件，数据库提交失败时清理本次新建的附件。

安卓手动/安全备份采用独立信封：

```json
{
  "format": "coc.logbook.android",
  "formatVersion": 1,
  "exportedAt": "ISO 8601",
  "restoreScope": ["modules", "records", "characters"],
  "snapshot": {
    "schemaVersion": 2,
    "exportedAt": "ISO 8601",
    "modules": [],
    "records": [],
    "characters": [],
    "settings": { "theme": "light", "filterPreset": {} }
  }
}
```

外层故意不设置 schemaVersion，当前桌面恢复校验会拒绝，防止它套用现有整库覆盖规则清空专属资料、闲记或剥除正文。桌面双向安全恢复完成之前，不提供“已兼容电脑恢复”的承诺。归档 URI 不来自备份，不能恢复电脑路径或用文件内容替用户授权。


代码格式和 lint 使用仓库已安装工具，在仓库根执行：

安卓构建脚本读取 JAVA_HOME（JDK 21）及 ANDROID_HOME（或 ANDROID_SDK_ROOT），尊重已有 GRADLE_USER_HOME。缺少工具时给出明确提示，不再写死旧电脑的 F 盘路径。浏览器预览不需要这些安卓工具。

最终 debug APK：`mobile/android/app/build/outputs/apk/debug/app-debug.apk`。构建会生成 www 与 Android assets，不直接编辑这些输出。

`src/MobileApp` 按页面/私有组件的同名目录组织；`src/data` 是多个页面共用的备份和原生契约。导出和过滤只读引用现有桌面共享代码，没有新建伪造 HTTP 接口，也没有启用生产 Mock。
