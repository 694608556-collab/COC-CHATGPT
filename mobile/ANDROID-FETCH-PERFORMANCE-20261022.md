## 范围与对照

用户要求 APK 与 IPA 一并优化。iPhone 14 Pro、Wi-Fi、114 场全部成功、从开始到最终保存的 41 秒仍是用户的 iOS 实机基线；此前 Edge 模拟 HTTP 的 300 场界面测量不能代替它，也不作为 Android 总耗时。

Android 使用 HttpURLConnection，区别于 iOS 每次创建并销毁 URLSession 的旧实现。S9/API28 独立包使用公开 loopback HTTP 响应，按生产相同的 open/read-to-EOF/close/disconnect 生命周期请求 114 次，仅接受 1 条 socket（463.479ms）。它证明该设备这个生命周期已能复用连接，不测外部 HTTPS/TLS/真实服务。没有移植 iOS 会话实现或删除 disconnect。参考 [Android 官方连接复用说明](https://developer.android.com/reference/java/net/HttpURLConnection)。一次初始探针因 IPv6 loopback 监听与 IPv4 客户端不一致连接失败，固定 IPv4 后通过；该失败不是应用缺陷。

## 已确认的本地传输开销

RawJson 原先逐字符经过 PushbackReader/BufferedReader 并逐字符调用 Writer。公开 1,220,014 UTF-16 单元的真实 RawJson 路径，修复前精确输出成立，但分块回归失败：1,220,014 次 Writer 调用，S9 275.775ms。修复后 149 次写入，首次 S9 86.469ms，完整输出逐字符相同。

现以每游标固定 32,768 字符输入缓冲和 8,192 字符输出缓冲传输，仍扫描每个字符保持原始词元边界；数字、转义、Unicode 不反序列化/重编码为新的 JSON 值。缓冲不随正文大小增长；不跳过 SnapshotStream 校验、不改 FetchBatch 的来源身份比较、分段摘要、全目标覆盖、目录授权、CAS、事务回滚、64MiB 或自动备份。
