# UI 试验 3：补齐长表单与可见区域适配

接续 `1e2d327`（试验二原尺寸修正版），继续使用 `codex/ui-optimization-experiment`。页面显示“0.2.14 · 试验 3”，包版本 / versionCode 仍为 0.2.14 / 17。用户明确排除放大控件，本轮没有再调整按钮、输入框、手柄、字体或候选行的原尺寸，卡片间距仍为 8px。

## 第五条的完成内容

- 角色姓名候选改为浮动菜单，根据输入框和当前可见区域向上／向下展开，限制在页头与编辑底栏之间，限制宽高并独立滚动。键盘选中的候选会滚入菜单可见范围，继续支持点选、输入筛选、上下键／回车、Escape 和系统返回先关闭候选。输入法处于合成状态或旧式 229 按键时，不把确认键当成候选选择。只填姓名，不改变模组 PC/PL。
- 编辑模组、场次和角色时，保存／取消按钮固定在当前可见区域底部。编辑期间原本不可用的三模块导航由编辑操作区临时替代，退出编辑后恢复；不新增重复按钮。进入编辑时收起旧成功提示，避免占用底部空间；错误反馈保留。原表单校验、保存锁、失败保留草稿及取消确认保留。
- 观察可见区域尺寸及偏移，更新编辑底栏和候选位置；输入焦点在键盘变化后尽量滚入标题／底栏之间。无 VisualViewport 时回退窗口尺寸及 resize。保存错误自动滚入可见区域，不丢弃输入。只在聚焦／视口变化时辅助定位，不锁住用户正常滚动。
- 设置分区按使用关系相邻排列：阅读／主题、自动备份／备份恢复、表格／归档位置／归档文件，清空数据单独保留在数据工具末尾，开发说明／版本信息在后。全部原按钮、说明和版本原文保留，不增加折叠隐藏。

定位参考 [VisualViewport 官方说明](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport)。实现使用普通窗口与可选 VisualViewport，不依赖 VirtualKeyboard、Popover 或新 CSS 视口单位。此说明不能当作 WebView 78 实机兼容通过。
