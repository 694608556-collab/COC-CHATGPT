## 一次展示契约

`LogbookPlugin.claimFirstLaunchIntro()` 为无参数原生方法，返回 `{show:boolean}`，不涉及 HTTP、鉴权、上传或跑团 JSON。它只访问 `app-presentation` 私有 SharedPreferences 的 `first-welcome-shown`：已存在返回 false；首次先同步 commit 标记成功，再返回 true，写入失败拒绝。标记不带版本号、不在归档设置／SQLite／备份中，不被业务导入或清空覆盖。先持久化再展示，避免欢迎页途中退出后重播。

前端复用唯一 Logbook 桥接代理，不重复注册插件；`PresentationPort` 与上述已实现 Java 方法一一对应，没有未知响应字段或生产 Mock。领取异常／500ms 超时只跳过欢迎展示，不阻断主应用或产生保存／备份提示，迟到许可不再重播。字体仍等待八份原字体；初始概览读取与字体／展示许可并行，不为欢迎页再次读取正文。`AppLaunch` 在显示期间并行启动业务，1.6 秒后移除欢迎层；动画时长不是整机启动耗时，也不能取消 Android 系统本身的启动画面。

浏览器验收仅在 `/?first-launch-preview=1` 显式开启，以独立 localStorage 模拟安装级标记，业务 IndexedDB 清空／导入不影响它；普通 `/` 不消费展示许可。该查询开关及模拟存储不进入正式启动路径，不提供正式包强制重播入口。

## 验证及限制

新增 `first-launch.spec.ts` 先在旧代码上失败（欢迎区不存在），顶部旧副标题检查也失败；实现后验证首次显示、1.6 秒结束、原图标可加载、导入／设置／清空／重开不重播、关闭期间再次打开不重播、后台信号清理。`release-ui.spec.ts` 核对顶部对齐、无副标题、版本页透明无边框及灰字品牌文案。截图停在 CSS 全显帧仅用于视觉核对，不延长真实动画。

本轮追加样式回归先复现：两行字号／字重／字距不一致、logo 距返回按钮约 79px、页尾居中，以及 320px 窄屏页尾与模块文字偏差 2px。最小 CSS 修复后四项欢迎／正式界面流程通过，保留原字体资源、按钮大小与全部业务流程。本轮视觉截图已检查，但尚无用户对新位置的实机接受结论。

完整 79 项浏览器流程（5.2 分钟）、四项最终欢迎／正式界面专项、61 项单元测试、39 项原生元数据辅助检查、类型／ESLint／格式检查及正式签名构建通过。展示接口异常／超时的单元测试只验证前端边界；原生元数据辅助检查不运行 Android bridge／SharedPreferences／SAF。最终 APK 再次核对网页与原字体资源一致；SDK XML／flatDir 警告未导致构建失败，不能据此宣称所有设备已兼容。

本轮没有安装正式包或修改原／独立测试版，**安装后首次显示、杀进程重开、覆盖升级保留展示标记、Android 9 / WebView 78 实际动画及其他机型仍待真机验证**。不能用浏览器 localStorage 的持久化测试当作安卓 SharedPreferences 真机证据。
