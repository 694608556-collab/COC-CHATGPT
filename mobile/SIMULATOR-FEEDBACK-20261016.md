## 六项实施情况

1. **启动瞬间的放大图标**：原启动主题 `Theme.SplashScreen` 直接使用完整 launcher PNG，造成额外的大图预览。Android 9–11 改为原应用背景色的无图标启动主题；Android 12+ 单独设置透明系统启动图标、相同背景，并在第一帧退出时立即移除系统预览。WebView 尚未绘制网页时也使用相同背景，常规应用主题不改。桌面图标、应用顶部 logo 和原 1.6 秒首次欢迎页保留，欢迎标记不重置、不增加延时。Android 12+ 的系统启动窗口及进入动画由系统管理，不能声称全部取消；本轮没有执行模拟器／真机逐帧验收，仍须新包复查。
2. **设置版本说明**：仅删除设置页的“跑团记录·调查员 · 记录每一次探索”，保留标题版本、本机保存、联网范围及制作者四行；欢迎页两行文案保留。设置页改为列布局，版本说明推至页面末端，底部预留约导航高度加小间隙，替代原 186px 大空白；在 320／412px 检查末端与导航间距 6–24px、文字左对齐。
3. **文本框角落小点**：文本域取消 resize，隐藏 WebKit resize 角标，仍可触摸／键盘滚动查看全部内容；公开四行经历保存重开后完整一致。
4. **白底细灰边框紧凑化**：普通按钮 34→30px，输入框约 32px，技能／物品输入同步压紧；文本域默认四行→三行、最小 72px；普通卡片、阅读消息、统计卡及记录卡减少纵向内留白，去掉卡片末段多余下边距。字体、正文行高、内容不变；返回、拖动手柄、底部导航及非白底边框的独立操作区域沿用既有尺寸。新需求替代历史“普通按钮固定 34px”的样式断言，不恢复之前被用户拒绝的放大方案。
5. **与电脑相同文件名**：将原桌面 Windows 名称清理与导出命名提为无 Node 依赖的共享函数，电脑服务和手机共同调用；不再使用手机的“场次名／模组-合成”简化名或原生随机八位尾缀，首份保留请求名，重名按电脑规则编号 ` (2)`、` (3)`，绝不打开旧文件覆盖。SAF 读取目录中已有名称后创建新文档，并以实际返回的文件名登记；创建后失败只清理新文档。命名锁仅覆盖查重与创建，后续文件 I/O 不占用元数据事务。移动端正常文件名上限允许完整 120 字符主名加扩展及编号，路径分隔符／控制字符／单独 `.` 和 `..` 仍拒绝。
6. **导出说明**：只加粗“按当前过滤设置导出。”，其余说明及导出内容保留。

## 文件名契约

- 单场／批量逐场：`跑团日期YYYYMMDD + 模组名 + 场次名 + 格式后缀.扩展名`，没有日期使用“日期未知”；带图 DOC 后缀“带图”，纯对话 DOC 后缀“对话”，原始 JSON 后缀“原始”。
- 合成：`生成日期YYYYMMDD + 模组名 + 合集.扩展名`；电脑已有 TXT／DOCX／PDF 格式完全一致，手机既有其他合成格式保留并使用相同前缀规则。
- 记录表格：`COC跑团记录YYYYMMDD.xlsx`；单模组 CSV 为同前缀 `.csv`，多模组 CSV 与电脑一样打成同前缀 `.zip`，内部按模组命名。清理后 CSV 名称碰撞时两端均编号保留，不把其中一个模组覆盖掉。
- 日期与电脑既有实现完全相同，使用 ISO 日期部分，不另改成本地时区规则；Windows 非法字符替换、保留名及 120 字符主名规则复用原实现。
- 示例：`20260506模组甲第 4 场.txt`、`20260506模组甲第 4 场 (2).txt`、`20261016模组甲合集.txt`、`COC跑团记录20261016.xlsx`。
- 已存在的随机尾缀旧文件不重命名、不删除；归档位置结构及旧文件登记保留。
