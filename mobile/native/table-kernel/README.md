# Read-only table accelerator

Android JNI and the iOS C bridge compile the same C++17 parser and unmodified
Expat 2.9.0 release sources. The upstream release URL, archive SHA-256 and every
copied upstream file digest are in `vendor/expat/UPSTREAM-SHA256.json`.
`expat_config.h` is the local POSIX configuration; DTD/general entities are
disabled. The complete upstream license is copied into `www/licenses/expat.txt`
by both ordinary web builds, and travels inside the APK/IPA.

The host captures a private immutable snapshot at complete EOF while computing
its SHA-256. The accelerator verifies the complete classic ZIP envelope, every
payload CRC/DEFLATE endpoint, relationships, shared strings and every worksheet
cell before returning any fixed-template projection. All worksheet tasks join
before returning. Formula results are read, never executed. JS uses the same
existing cell validator and complete seven-edition template mapper. The live
native owner, archive grant/location and revision are checked again before the
draft is displayed. No write/restore authority is granted by the projection.

The 2 MiB source/SST/projection and 8 MiB expanded budgets bound this resident
optimization only. Unsupported format spellings, encodings or cache overflow
return `supported:false`. The host then materializes the **entire** proven
snapshot, syncs/rechecks it, and uses the complete existing streaming path.
No larger file is rejected by these cache constants. Staging/transactions keep
their original storage checks, FULL durability, validation and rollback.

Startup warming parses only literal public numeric XML and retains no input or
result. Android may query already-authorized root metadata to start a provider;
it does not enumerate/open user files and it does not cache authorization.

`scripts/build-table-kernel.sh` compiles the exact production sources for macOS
native checks. `scripts/check-table-kernel.mjs <probe>` compares the executable
with the complete JS reader cell by cell and with the original SheetJS template
importer for a complete public draft. Android instrumentation also verifies the
same public corpus and source SHA, RAM ownership, durable full fallback and
cleanup; S9 runs both 32-bit and 64-bit kernels. Test observers are compile-time
disabled and checked absent in ordinary/release web bundles.
