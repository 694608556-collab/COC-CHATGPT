# COC 跑团记录簿

仅在本机运行的 Windows 10/11 x64 免安装桌面应用，用于整理海豹跑团日志和管理第六版、第七版调查员角色卡。

## 开发与打包

1. 安装 Node.js 22 或更高版本和 pnpm。
2. 在项目目录运行 `pnpm install`。
3. 运行 `pnpm dev` 启动开发版。
4. 运行 `pnpm verify` 执行代码检查、类型检查、测试和生产构建。
5. 运行 `pnpm package` 生成 Windows x64 免安装程序。

## 数据与隐私

- 正式数据保存在免安装程序同级的 `data` 文件夹。
- 归档目录可在应用内修改；默认位于“文档\\COC跑团记录”。
- 无登录、无云数据库。除用户主动检测或下载海豹日志外，不访问网络。
- 移动应用时请连同 `data` 文件夹一起移动；卸载时直接删除整个免安装目录即可。

## 发布说明

未签名的测试版可能触发 Windows SmartScreen 提示。正式发布包附带 SHA-256 校验值和第三方许可证说明。
