# 公司电脑用的脚本

三个双击即可运行的批处理脚本（Windows + 中文系统）。它们默认操作**脚本自己所在的仓库**
（也就是 `tools` 的上一级目录），项目文件夹放在哪里、叫什么名字都不用改脚本；
也可以把项目文件夹直接拖到脚本图标上，临时指定别的位置。

| 脚本                            | 用途                                                                                     |
| ------------------------------- | ---------------------------------------------------------------------------------------- |
| 公司电脑-一键同步并启动开发.bat | 第一次会从 GitHub 下载源码；以后每次都先拉取最新进度，再安装依赖并启动开发模式           |
| 公司电脑-一键提交并推送.bat     | 把本机改动提交并推送到 GitHub。推送成功前不要关机，否则进度会丢                          |
| 公司电脑-一键跑测试并打包.bat   | 依次执行 pnpm install、pnpm build、pnpm test、pnpm package，产物输出到 dist 目录          |

## 打包产物

`pnpm package` 一次产出两个文件，用途不同：

| 文件                                         | 用途                                                                               |
| -------------------------------------------- | ---------------------------------------------------------------------------------- |
| `COC跑团记录簿-<版本>-win-x64.exe`           | **免安装版**。双击即用，数据存在程序旁边的 `data/` 目录，整个文件夹拷走就是全部数据 |
| `COC跑团记录簿-<版本>-Windows-x64-Setup.exe` | **安装包**。走安装向导，可自选安装位置，自动建快捷方式；数据存用户目录，卸载重装不丢 |

给朋友测试建议发**安装包**（体积只差约 0.3 MB，对方不用理解 `data/` 目录在哪）；
自用建议**免安装版**（数据跟着文件夹走，方便备份和搬迁）。

两个文件都没有代码签名，首次运行 Windows 会提示「已保护你的电脑」，
需要点「更多信息 → 仍要运行」；杀毒软件也可能提示，选「允许」即可。

- 工作分支：`v0.7.3`（同步脚本里写死了分支名，切换开发分支时要同步修改）
- 需要先装好 Git for Windows、Node.js 22 或更新版本；脚本会检查并在缺少 pnpm 时自动安装
- 脚本本体是 GBK 编码：cmd.exe 在中文 Windows 下解析 UTF-8 批处理会串码，所以不要把它转成 UTF-8
- 换电脑时：先把仓库 clone 到任意目录（`git clone -b v0.7.3 <仓库地址> <目录>`），
  之后直接双击目录里的这三个脚本即可，不需要再改任何路径
